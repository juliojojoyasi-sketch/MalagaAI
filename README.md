# MalagAI Android

Projet Android qui embarque la version offline/futuriste de MalagAI dans une WebView.

Package: com.malagai.app
Min SDK: 23
Target SDK: 36

## Compiler
Ouvrir ce dossier dans Android Studio puis lancer la synchronisation Gradle.
Pour un APK de test : Build > Build APK(s).
L'APK debug est généré dans app/build/outputs/apk/debug/.

Pour une version release distribuable, il faut signer l'APK avec une clé de release.
